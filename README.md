\# DVC Assignment - Dataset Version Control



\## Project Overview



This project demonstrates dataset version control using Git and DVC.



The Iris dataset is used as the sample dataset. DVC is used to track changes to the dataset while Git tracks the project files and DVC metadata.



\## Tools Used



\- Python

\- Pandas

\- Scikit-learn

\- Git

\- GitHub

\- DVC
